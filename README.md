A single joke about Monday mornings, written by a small program for the
make.fun bounty **Monday Morning Punchlines**.

Bounty page: https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc

## What it does

`main.ts` (Node, program/v1) writes one joke — at most 200 characters — to
`/output/entry.txt`, exactly as the competition gate requires: UTF-8 text,
no trailing newline. The joke was drafted against the published judge brief
(really about Monday mornings, a punchline that lands, surprise, economy of
words, freshness) from a field of candidates, then revised down to the
strongest line.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
